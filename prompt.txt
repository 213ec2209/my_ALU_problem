ALU operation
The ALU is an 8-bit combinational Arithmetic Logic Unit that operates on two 8-bit operands. The operation is determined by a 3-bit control signal, op. The output Y is computed directly from the current values of A, B, and op, without using any internal storage or feedback loops. The ALU uses basic digital logic elements such as adders, subtractors, AND/OR gates, XOR gates, and unsigned comparators. Being fully combinational, the design provides low-latency, predictable, and deterministic timing behavior.

Arithmetic operations are performed using 8-bit unsigned arithmetic, while logical operations are applied bitwise across the operands.

The ALU supports the following operations:

Addition (ADD)
Computes the sum of operands A and B.

Subtraction (SUB)

Bitwise OR

Compares operands A and B and sets the output to 1 if A is less than B; otherwise, sets the output to 0.
